Your computer will warn you the first time. That's expected. Conviea isn't signed with a paid certificate, so macOS and Windows treat it as an unknown app — the warning is about the missing certificate, not about anything found in the app. macOS: open Conviea, then System Settings → Privacy & Security → Open Anyway. Windows: More info → Run anyway. Once only; after that it opens normally. Every line of Conviea is public if you'd rather check before you trust it — read the source.
